# Shadow Zombie

Play the browser game: https://sabikunnaher131.github.io/Shadow_Zombiee/

Survive two levels in the dark: use the flashlight to reveal zombies, shoot them, collect batteries, and manage health and ammunition.

## Controls

- **WASD / Arrow keys:** Move
- **Mouse:** Aim
- **Hold left mouse button:** Fire
- **Space:** Toggle the brighter flashlight
- **R:** Reload
- **Shift:** Sprint
- **P:** Pause or resume

## Publish with GitHub Pages

For the first deployment, open **Settings → Pages** and select **GitHub Actions** under **Build and deployment → Source**. Then open **Actions → Deploy game to GitHub Pages → Run workflow**. Later pushes to `main` deploy automatically.

The site is a static HTML, CSS, JavaScript, and audio project. No build step or package installation is needed.
